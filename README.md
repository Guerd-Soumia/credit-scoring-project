**Project 13 — Octroi Décentralisé de Crédit & Analyse de Solvabilité**

## Goal
Build a multi-agent AI system that evaluates a borrower's default risk.

## Agents
- Agent 1: RNN — analyzes transaction sequences
- Agent 2: Random Forest — analyzes borrower profile
- Agent 3: Logistic Regression — makes final decision
